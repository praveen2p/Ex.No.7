4. Prompt Engineering Techniques

Learners should use different prompting strategies.

Technique	Application
Zero-shot Prompting	Generate an artifact without examples
Few-shot Prompting	Provide examples before generating
Persona Prompting	Assign AI an expert role
Reverse Prompting	Ask AI to determine what information is needed
Active Prompting	Ask AI questions to improve the task
Graph Prompting	Represent relationships between concepts
Iterative Prompting	Generate → evaluate → improve → verify
5. Example: Iterative Prompting

Suppose the learner wants to create a technical report on Smart Irrigation.

Stage 1 – Basic Prompt
Write a technical report about an AI-based smart irrigation system.

AI generates the first version.

Stage 2 – Add Persona
Act as an experienced agricultural IoT engineer.
Write a technical report about an AI-based smart irrigation
system for undergraduate engineering students.
Use technically accurate terminology and a formal academic style.
Stage 3 – Add Structure
Create the report using these sections:

1. Abstract
2. Introduction
3. Problem Statement
4. Objectives
5. System Architecture
6. Methodology
7. Hardware and Software
8. Results
9. Limitations
10. Conclusion
11. Future Scope
Stage 4 – Technical Review
Review the above report as a technical reviewer.

Identify:
1. Technically incorrect statements
2. Unsupported claims
3. Missing technical details
4. Logical inconsistencies
5. Ambiguous explanations

Do not rewrite the report yet.
First provide a list of problems.
Stage 5 – Improve
Now revise the report based on the identified problems.

Maintain the original meaning but:
- improve technical accuracy
- remove unsupported claims
- improve logical flow
- improve grammar
- improve readability
Stage 6 – Final Verification
Perform a final quality check.

Evaluate the document for:
- Grammar
- Technical accuracy
- Logical consistency
- Readability
- Repetition
- Potential plagiarism
- Unsupported claims

Give a score out of 10 for each criterion and
suggest corrections where required.
